# Support

Use GitHub Issues for usage questions, reproducible defects or scoped feature requests.

Before reporting a calculation mismatch, read [the compatibility status](docs/COMPATIBILITY.md) and include the complete reference metadata described in [CONTRIBUTING.md](CONTRIBUTING.md).

Security issues belong in private vulnerability reporting, not public discussions. This is a community-maintained pre-1.0 project; no response-time or numerical fitness warranty is provided.
